# ANSRA (가칭) — GEO 플랫폼 인터랙티브 목업

AI 검색 노출(GEO) 플랫폼의 화면 목업입니다. 백엔드는 연결되어 있지 않으며 **모든 수치는 예시 데이터**입니다.

- `index.html` — 랜딩 페이지
- `dashboard.html` — B2B 대시보드 (메뉴 13개)
- `runtime.js` — 템플릿을 그려 주는 작은 렌더러 (빌드 과정 없음)

로컬에서 보기: `python3 -m http.server` 실행 후 http://localhost:8000

신청 폼에 입력한 내용은 어디에도 전송되지 않습니다. 브랜드명 ANSRA는 가칭입니다.
